# What's new

Changes to Passage in plain language, newest first. Add an entry here for every change a user will notice. The "What's new" page in the app shows this file.

## 2026-11-10

- Every page now has a "?" button at the top right. It opens a panel that says what the page is for, lists the common tasks and links to the full guide.
- Lists of purchase orders and vendor invoices can be filtered, sorted, saved as views and exported to CSV.
- Vendor invoices show a due date and whether the invoice matches the receipt.
- Accounts payable: you can put every payment to a vendor on hold with a reason and release it again, a proposal that is running, paid or failed opens its payment run, and a completed run gives a remittance advice per vendor to download.

## 2026-11-03

- My work shows everything waiting for you in one place, with an Open link for each item.
- Products can be put in an item group and marked as tracked by batch, serial number or catch weight.
