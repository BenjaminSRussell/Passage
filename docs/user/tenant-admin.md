# Set up a company

For administrators. You create the legal entity, calendar, sites and people so others can start buying and selling.

## Before you start

- You have administrator access. If menu items are missing, ask the person who created your account.

## Create a legal entity

1. Open **Org** and choose **Legal entities**, then **Add legal entity**.
2. Enter **Code** (short and unique, for example DE01), **Name**, **Country**, **Accounting currency** and **Time zone**.
3. Select the add button to save.

You can also copy an existing legal entity with the copy form on the same page.

## Set up the fiscal calendar

1. Open **Fiscal calendars** and select **Add fiscal calendar**.
2. Enter **Code**, **Name**, **Pattern** and **First month of the fiscal year**.
3. Select **Generate fiscal year** to create the periods.

## Set up where work happens

1. **Operating units**: select **Add** and fill in the form.
2. **Sites**: select **Add site**.
3. **Warehouses**: select **Add warehouse**, linked to a site.
4. **Locations**: select **Add location**, linked to a warehouse.

## Add vendors and customers

1. Open **Parties** and select **New party**.
2. Choose **Type** (organization or person) and fill in the name.
3. Select **Create party**. The party number is assigned for you.
4. Check **Duplicate candidates** now and then to merge repeats.

## Give people access

1. Open **Admin**, then **Users** to see who has an account.
2. Open **Role catalogue** to see which roles exist. It is read-only.
3. Open **Role assignments** to give a person a role. Fill in the user and role, the dates it is valid, and the reason.
4. Open **Effective permissions** to check what a person can do.

## Numbering

Open **Sequences** under **Admin** to see and change how document numbers are issued.

## Common messages

| Message | What to do |
| --- | --- |
| You don't have permission to do this. | Ask an administrator for access if you need it. |
| You don't have the duty this action needs. | Ask an administrator to give you the role. |

## Not available yet

- **Creating products.** Products can be browsed under **Product information**, but there is no form to create one.
- **Pick-lists for people and roles.** Role assignments ask for ids or role names to be typed in.

## Glossary

- Legal entity: a company that keeps its own books.
- Operating unit: a part of a legal entity, such as a division.
- Site and warehouse: where stock is kept.
- Fiscal calendar: the periods your books are split into.
