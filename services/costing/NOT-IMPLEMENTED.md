# NOT-IMPLEMENTED — services/costing (PSG-20, wave 20, slices 1 to 6)

Every ticket deliverable and acceptance criterion not built yet, with its status and reason.
Slice 2 built marking, the valuation-type and valuation-ledger settlement rules, and the
inventory aging calculation, all as pure domain code with preview endpoints. Slice 3 built
standard cost versions end to end (reads, CSV import, copy with percent, activation preview,
atomic activation with `cost.changed`, the as-of cost lookup) and their screens. Slice 4 built
the valuation ledger and valuation category registries, saved aging bucket sets and stored
month-end aging snapshots with `agingsnapshot.created`, and their screens. Slice 5 built the
append-only `CostTransaction` projection with its producers' hook, the inventory value report by
product, site, warehouse and valuation type per valuation ledger, the tie-out to caller-supplied
ledger balances, the cost transaction drill-down and their screens. Slice 6 built manual cost
adjustments of on-hand value and of single receipts (preview, post with a MANUAL_ADJ cost
transaction, `cost.changed` for the primary valuation), stored reconciliation runs that emit
`reconciliation.diff` per differing group, and their screens. Rows that a slice only narrowed
are kept with what remains.
