# NOT-IMPLEMENTED: print (PSG-32, wave 32, slice 6)

Every PSG-32 deliverable or acceptance criterion that this service does not yet cover.
Status is either `later slice of PSG-32` (owned here, not built yet) or `handoff`
(needs code outside the wave's owned paths).

| Business documents (`POST /print/v1/documents:render`, issue #530) in Chinese, Japanese, Korean, Arabic, Hebrew, Thai and other scripts outside Latin, Greek and Cyrillic | Issue #530 | later slice of PSG-32 | The renderer embeds Go Regular and Go Bold, the only freely licensed fonts in the module graph; they cover Latin with its extended letters, Greek and Cyrillic. A character they lack prints as U+FFFD with the original kept as ActualText, and the response counts them in `X-Passage-Unprintable-Characters`; the document is not refused. Covering the other scripts needs a font that has them added to the repository (a pan-CJK font is 10 to 20 MB per weight), and Arabic and Hebrew also need right-to-left layout and shaping, which the renderer does not do. Delivered in slice 6 (row replaced above): 1 in label layouts and a bar code width check.
`internal/domain/layouts.go` holds compact 2 x 1 and 3 x 1 in layouts for `LP_LABEL`,
`LOCATION_LABEL` and `ITEM_LABEL` (the GS1 carton label is 4 x 6 in only, §6.32.15), printed per
device at dispatch. `SizeLabel` now also refuses a Code 128 bar code that, with its 10-module
quiet zones, is wider than the media (PRN-0007). The GS1 bar code switches between Code 128
subsets B and C (`gs1Code128`), which brought the carton and full item bar codes inside a 4 in
label (in subset B alone they were wider than the media and printed clipped). Golden:
`testdata/golden/lp-label-2x1.zpl`. Tests: `internal/domain/layouts_test.go`, `code128_test.go`
and `internal/api/api_test.go`.

Delivered in slice 5 (row narrowed above): label geometry per device. `domain.SizeForDevice`
sizes each ZPL label at dispatch (scaled from 203 dpi, `^PW`/`^LL` from the media, the
template's own `^PW`/`^LL` replaced); `domain.Dispatch` skips a device that refuses a label
(PRN-0007) without retrying it and reports PRN-0007 when every device refused. Goldens:
`testdata/golden/lp-label-4x6-203.zpl` and `lp-label-4x6-300.zpl`. Tests:
`internal/domain/geometry_test.go`, `dispatch_test.go` and `internal/api/api_test.go`.
