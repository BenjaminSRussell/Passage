# NOT-IMPLEMENTED — ledger (PSG-11, wave 11, after slice 6)

Every PSG-11 deliverable and acceptance criterion not yet fully built. Slice 2
added shared reason codes (D6, FR-11.15), reversal reason rules, negative
(storno) postings in the balance projection (BR-11.16), the reason-code API and
the reason-code and reverse screens. Slice 3 added account structures with
constraint rows, versions and activation (D1, FR-11.3), structure validation in
posting and `/validate`, the structure version in the combination hash (FR-11.4),
the per-ledger dimension value register with effective dates and suspension
(FR-11.2, `LEDGER_DIMENSION_INACTIVE`), their API, and the structure and
dimension value screens. Slice 4 added default description templates
(FR-11.17: `description_template`, migration 0008, RLS with a legal-entity scope
policy), their API, the posting stage that fills an omitted description and
omitted line texts (AC-11.19) with the `LEDGER_DESCRIPTION_TRUNCATED` notice, and
the template list and form screens. Slice 5 added the manual journal workspace
(D5, FR-11.9, BR-11.10): journal names (`journal_name`, migration 0009, RLS) with
approval, self-approval, reversal-reason, reconciliation-account and lines-limit
controls; journal batches and lines (`journal_batch`, `journal_batch_line`, RLS
with legal-entity scope) with the BR-11.10 state machine, `version`/`ETag` and
`If-Match`; submit (validation with the posting rules), approve/reject, cancel
and post (entry and batch status in one transaction, `Idempotency-Key`);
`dev.passage.ledger.batch.statuschanged.v1` through the outbox; and the journal
name, batch list, new batch and batch screens. Slice 6 added the ledger
transactions inquiry (FR-11.14): `GET /journal-lines` with keyset paging and
account-range, posting-date, voucher, source-system and `dim.{ATTRIBUTE}`
filters, the indexes for it (migration 0010), the Ledger transactions screen
(filters in the address, load more, drill to the entry) and the drill from a
trial balance account to its lines. Status is either `later slice of PSG-11`
(owned by this service, next slices) or `handoff` (needs another owner or a
path outside `services/ledger/` and `apps/web/src/modules/ledger/`).
