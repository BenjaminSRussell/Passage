# NOT-IMPLEMENTED: consolidation (PSG-40, wave 40)

Slices 1 to 3 are stateless: pure consolidation rules, the elimination,
E6 dividend, translation, profit-in-inventory, equity-method, divestiture, IC
difference, validation, reclassification dry-run and top-side journal
previews, and the web pages for each. Wave 40 AC4 adds stored runs: the run
header, unit balances, eliminations and statement lines, immutable and
versioned, with start, list, get and statements APIs and the
`consol.run.completed` event.
Every deliverable and acceptance criterion not listed as built in the README
is below, with its status and reason.
